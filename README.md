# 紫微斗數排盤與多面向深度分析系統 (Ziwei Doushu Web)

基於 Vue 3 + TypeScript + Vite 開發的純前端現代化紫微斗數排盤與全方位人生深度解讀系統。

## 🌟 核心特色

1. **嚴謹的核心排盤演算法**：
   - 支援「本命天盤」、「大限盤」、「流年盤」三盤合一與宮位重疊。
   - 遵循古制嚴格排盤：包含十四主星、六吉六煞、四化（生年/大限/流年）、祿存、天馬，以及神煞星曜（天刑、陰煞、華蓋等）。
   - 農曆換算嚴格恪守指定命理規則：「閏月一律直接算當月」。

2. **20 份命理講義知識庫深度轉譯**：
   - 涵蓋 13 大人生面向：整體格局、婚姻感情、財運求財、事業升遷、讀書考試、買房祖業、子女親子、出外移居、精神福德、人際合夥、長輩手足、健康疾難、宗教修行。
   - 👑 **通俗大白話解讀**：不用懂艱深斗數術語，一分鐘看懂人生重心。

3. **直言不諱・拒絕粉飾太平**：
   - ⚠️ **致命性格盲點與隱患剖析**：直擊主星性格死穴與煞曜衝破。
   - 🛠️ **自我修為與具體改進功課**：提供打破命運慣性的具體行為處方。

4. **精準對照命盤星曜**：
   - 告別「生搬硬套」：天刑在命身宮才論仙佛宿緣神通，在奴僕宮則論人際原則是非；科甲星、疾厄臟腑、名宿格局皆嚴格依盤面動態判定。

5. **佛法正信與心靈指引**：
   - 完整整合聖嚴法師 16 大心靈環保課題、生活實踐心法與 YouTube 大法鼓、法鼓全集延伸學習連結。

## 🛠️ 本地開發與運行

### 安裝依賴
```bash
npm install
```

### 啟動開發伺服器
```bash
npm run dev
```

### 構建生產版本
```bash
npm run build
```

### 本地預覽生產版本
```bash
npm run preview
```
